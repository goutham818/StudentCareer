Required CSV Columns

Your uploaded CSV must include these exact column names. Any mismatch will fail validation.

name Text Student Name
roll_number Text (Unique) e.g. CS2026005
department Text e.g. Information Technology
semester Int Semester level (e.g. 6)
cgpa Float Current Cumulative GPA (0-10)
attendance Float Attendance Percentage (0-100)
skills Text Comma separated skills list
interests Text Comma separated interests list
internal_marks Float Marks in internal exams (0-100)
assignment_score Float Assignment average score (0-100)
previous_cgpa Float Prior semester CGPA (0-10)
category Text Excellent, Good, Average, Needs Improvement
